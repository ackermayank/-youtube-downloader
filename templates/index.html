FFmpeg Setup Guide

FFmpeg is a free, open-source tool used by yt-dlp to merge high-definition video and audio tracks (1080p, 4K, 8K) and to convert audio to MP3.

Windows (Recommended)

Open PowerShell and run:

winget install Gyan.FFmpeg
macOS

In Terminal, run with Homebrew:

brew install ffmpeg
Linux (Ubuntu/Debian)
sudo apt update && sudo apt install ffmpeg

After installing, restart the app and the badge will turn green!
